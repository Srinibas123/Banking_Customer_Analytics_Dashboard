# Banking_Customer_Analytics_dashboard
End-to-end banking analytics project: 3,000-client dataset explored with Python (pandas, seaborn) and visualised in a multi-page Power BI dashboard — loan &amp; deposit analysis by demographics, income bands, occupation, and banking relationships.
